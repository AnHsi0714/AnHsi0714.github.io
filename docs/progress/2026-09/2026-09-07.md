### 內容審閱：excerpt、架構、排版、名詞統一建議

比對站上另外兩篇論文筆記（`social-engagement-misinformation.md`、`snappi-personal-data-stickers.md`）的既有慣例，抓出四類名詞不一致：

- 「短影音」／「短影片」交錯：標題已用「短影音」，正文卻混用，統一改成「短影音」指媒介本身，單一影片計數時用「影片」（例如「420 支影片」）不加「短」。

- 「使用者」／「分享者」／「創作者」／「發布者」四個詞其實都在指「貼片分享活動的人」，統一成「分享者」——理由是這篇論文的核心框架就是「activity sharing／五大分享目的」，用分享者最貼合論文自己的語彙，也能跟「觀眾」形成清楚的發布／觀看二元對照；「使用者」是另外兩篇論文（研究對象是 App／平台使用者）的慣用詞，這篇分析單位是「影片」而非「帳號行為」，不必強套。

同時發現三處遺留的 HTML 註解（是使用者寫給自己、之後要轉表格的草稿標記）、一處偽表格（純文字排版、不是真正的 markdown 表格語法）、「研究方法」標題在兩個不同層級重複出現、五大分享目的清單跟後面表格的四類分類名詞對不上（後來查證是論文原文本來就把「情緒支持」與「表達自身形象」合併討論，不是翻譯落差）等問題，先列成清單交給使用者確認要不要動，之後陸續在同一天處理掉。

### 對照原文 PDF 查證，修正三處數據誤讀

使用者指出幾個數字可能引用錯誤，這次直接下載論文原文 PDF（`pdftotext -layout` 抽成純文字後用 grep/read 比對，因為環境沒有 `pdftoppm`），逐句核對：

- 89.95% 原本被讀成「跑步影片中有多少比例用了結論數值摘要」，但原文是「69 支用了這個手法的影片裡，跑步佔 62 支（89.95%）」——是手法使用者裡的領域佔比，不是該領域影片本身的使用率。改成兩欄表格（影片數＋佔比）並加註解釋這個區別。
- 「活動後反思」表格原本用 15/31（48.39%）當跑步的代表數字，但這其實是「同時呈現兩種尺度目標」這個子集合的數字，整體數字應該是 24/56（47.86%）；表格標題也從籠統的「同時有活動後反思的比例」改成更精確的「事後反思中重新提及目標的比例」（因為原文這組數字講的是「反思時有沒有回頭提到當初設的目標」，不是「有沒有反思」這個更廣的概念），子集數字保留但標明是子集。
- 註腳 2 原本用「推測是 420，因為 140 對不上」的猜測語氣，但原文直接寫明：過去 HCI／CSCW 對 TikTok 影片的質性分析通常落在 100～300 支之間，作者刻意選在這個範圍高端，因此定為 420；改成直接引用這個理由。順便發現同一段「資料抓取」的算術錯誤——原文是「800 部初始 → 剔除 40 部不相關/非英文 → 剩 760 部」，草稿誤把「剩餘數」寫成「剔除數」，一併修正。
- 補上一則遺漏的限制：短影音是透過演算法推薦的動態呈現，分享者可能受歡迎內容影響調整分享方式；作者比較過高低人氣影片的敘事手法後未發現顯著差異（主要差異在製作精緻度與活動品質本身），但仍視為潛在限制。

### 新增五個知識詞條：微型趨勢、量化／質化、歸納法／演繹法

使用者要求把「微型趨勢」「量化」「質化」也做成知識點，並確認是否合適：微型趨勢是論文原文實際用詞（"micro-trends"），指蒐集資料時因週期性活動被放大的樣本偏誤，是具體的研究方法概念，判斷適合建點；量化／質化本身是基礎詞彙，站上目前的知識點門檻偏向專門術語（對照 snappi 那篇只標了 reflexive thematic analysis、thematic coding 這種相對特化的方法論詞），但因為型別系統本來就有 `contrasts-with` 這個關係型別專門處理「容易混淆的一對」，還是照要求建了，兩者互相用 `contrasts-with` 連結。

隨後使用者追問歸納法／演繹法要不要也建點、能否參考 `information-visualization` 節點的做法。查過 `information-visualization` 的 `application` 物件形式後判斷：那個機制是給「同一個詞被多篇文章共用」時依情境只顯示一句用，不是用來把兩個不同概念塞進同一個節點；歸納法／演繹法比較貼近的既有範例反而是剛建的量化／質化，或是 `visual-analytics`／`interactive-data-exploration`／`information-visualization` 這組——各自獨立成節點、用 `relatedNodes` 串連。因此建了 `inductive-reasoning`／`deductive-reasoning` 兩個獨立節點，`type` 用 `related` 而非 `contrasts-with`（因為論文裡兩者是先歸納、再演繹的接續步驟，不是互斥的二選一），並回頭在 `thematic-coding` 補上反向連結。

五個節點（`micro-trends`、`quantitative-data`、`qualitative-data`、`inductive-reasoning`、`deductive-reasoning`）都同步寫進 [knowledge.json](../../../content/knowledge.json)／[knowledge.en.json](../../../content/knowledge.en.json)，`category: RESEARCH`，`relatedArticles` 指回這篇短影音筆記，並在中英文兩篇文章對應段落補上 `data-term` 標記（遵守「每個 H2/H3 小節第一次出現才標」的規則，同一小節內的第二次出現維持不標）。跑過 `/knowledge-coverage` skill 確認：無重複標記、無漏標、中英文標記 id 集合一致、五個 id 在中英兩份 knowledge.json 都有對應項目、`relatedArticles` 反查沒有過期參照。
