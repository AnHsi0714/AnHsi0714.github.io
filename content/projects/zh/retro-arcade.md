# 復古遊戲機台 Retro Arcade

## 專案簡介

一條橫向捲動的復古遊戲廳長廊。玩家左右移動，沿途經過一台台機台，走到機台前按鍵進入遊戲，離開後回到長廊，再挑下一台。每台機台是一款受經典街機啟發的小遊戲，並加入自己設計的機制。

目前進度：尚未開始，目前在規劃階段。

### 機台清單

| 機台          | 靈感來源       | 重點功能                                                                         |
| ------------- | -------------- | -------------------------------------------------------------------------------- |
| Snake         | 貪吃蛇         | 蘋果生成、移動與碰撞、積分                                                       |
| Breakout      | 打磚塊         | 關卡地圖、球與磚塊的碰撞邏輯、積分                                               |
| Star Defender | Space Invaders | 生命、玩家移動、攻擊、敵人群體移動                                               |
| Meteor Drift  | Asteroids      | 三條命、穿牆移動（類似瑪利歐的畫面邊緣循環）、積分、隕石被擊中後碎裂、外星人出現 |
| Maze Chomper  | Pac-Man        | 迷宮地圖、四隻移動邏輯不同的追逐者、積分與音效                                   |

### 製作順序

由簡單到複雜：Snake、Breakout、Star Defender、Meteor Drift、Maze Chomper。先用 Snake 定下機台模組的共用介面（遊戲迴圈、輸入處理、進入與離開流程），後面的遊戲沿用。

### 原創與版權

玩法規則本身不受著作權保護，但原作的美術、音樂、音效、角色與迷宮配置受保護，遊戲名稱也常是商標。因此本專案的圖片與音訊皆為自製或授權明確的素材，角色與迷宮自行設計，除了通用名稱的 Snake 與 Breakout，其餘遊戲使用自己取的名稱。

## 技術架構

- **前端**：Vite + TypeScript，純靜態打包，部署到 GitHub Pages。
- **繪圖**：HTML canvas。
- **架構**：長廊是主場景，每款遊戲是獨立模組，共用同一套遊戲迴圈與輸入處理，新增機台只需要新增一個模組。

## 遊戲設計重點

### Meteor Drift

- 穿牆：物件座標超出畫面邊界時，對畫面寬高取模，從另一側出現。
- 碎裂：大隕石被擊中後分裂成兩顆較小的隕石，最小的被擊中後消失。
- 外星人：定時出現的敵人，會射擊玩家，擊毀可得較高分數。

### Maze Chomper

- 地圖以格子（tile）表示，移動與轉彎都以格子為單位判斷。
- 四隻追逐者各有不同的目標選擇邏輯（例如直接追逐、預判前進方向、包抄、隨機游走）。

## 結語

### 預期挑戰

| 挑戰                   | 預計做法                                       |
| ---------------------- | ---------------------------------------------- |
| 多個遊戲共用同一套架構 | 先抽出遊戲介面，Snake 完成後再檢討是否需要調整 |
| 範圍容易膨脹           | 先完成「長廊 + 一台機台」，能玩了再加下一台    |
| 四隻追逐者的行為差異   | 把「目標格選擇」獨立成函式，每隻只替換這個函式 |
| 素材版權               | 只使用自製或 CC0 素材，並記錄來源              |
