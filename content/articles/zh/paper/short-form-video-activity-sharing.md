> 撰寫期間：2026-09-03 – 2026-09-07

**原文連結**：[了解人們如何在短影音中分享個人活動](https://denniswang.net/static/wang2025.pdf)（Dennis Wang、Jun Zhu、Daniel A. Epstein，CSCW 2025）

## 簡介

這篇論文探討人們如何透過短影音分享自己的活動，以及在活動前、活動中與活動後，會使用哪些敘事策略呈現活動資訊。

研究主要想了解：人們在短影音中會分享哪些活動資訊？又會透過哪些策略呈現這些資訊，以及這些策略如何支持不同的分享目的？

## 研究背景

人們分享活動主要有五大目的：

1. 尋求資訊支持(給建議)
2. 尋求情緒支持
3. 尋求動力與課責(透過公開自己的目標，獲得他人的鼓勵，同時增加自己完成目標的責任感)
4. 影響或激勵他人(和 3 相反，變成影響他人)
5. 自我呈現(透過分享活動與成果建立或維持特定的自我形象)

不一定只有一個目的，分享可能同時包含多個目的。
因此研究想知道在短影音平台，人們有哪些分享策略，以及是支持或忽略這五大目的。

短影音有三個特點：

1. 內容時間短(15 秒~5 分鐘)
2. 適合行動裝置使用
3. 個人化演算法推薦

### 研究方法

對短影音做質性分析、TikTok 平台上 420 支影片(跑步、素描、學習)做編碼。

#### 選定領域

作者提到檢查平台內容是否有足夠數量供研究分析，以及確保影片內容真的在頻繁分享其主題資訊，最終選定上述的三個領域因為有不同方式呈現：

| 領域              | 例子 | 進度／活動資訊比較常怎麼呈現 |
| ----------------- | ---- | ---------------------------- |
| Physical Activity | 跑步 | 數字、里程、時間、速度       |
| Creativity        | 畫畫 | 作品變化、製作階段           |
| Productivity      | 讀書 | 時間、待辦事項、學習過程     |

在其他領域，例如：騎車、數位音樂創作等，發現內容通常是教學性質，而非分享活動本身。

讀到這邊有個疑問，作者雖然強調研究不應侷限於特定 domain，但最後仍只選擇 Physical Activity、Creativity 和 Productivity 三個領域。這三個領域可以增加活動類型的多樣性，但是否足以代表整體的 activity sharing？

談到用關鍵字，作者用了 #runtok 而非 #run 或 #marathon，原因是要聚焦在特定領域，卻又必須排除非該領域資訊(逃跑、奔跑的狗)和避免縮小活動內容(跑步→馬拉松)的關鍵字。

團隊使用 TikTok API 蒐集美國影片，目的是專注在英文資訊和確保美國研究人員有足夠文化背景解讀影片，分十天五個日期蒐集，想減少<span data-term="micro-trends">微型趨勢</span>(一週內舉辦素描活動)，例如：每週活動，同時為了人們可能在一週內完成的活動，總共蒐集 3569 部，跑步 1750、素描 936、學習 883。

這邊我認為是很有趣也很細節的部份，在蒐集資料時我們一般都是直接關鍵字下去，但作者透過領域特定的 hashtag，避免需要進行複雜的資料清洗，是值得學習的細節。此外選擇的時段也很細節，想同時減少微型趨勢又要蒐集一週定期活動，於是採用多個時間點進行蒐集。這讓我發現研究資料的品質往往在分析之前就已經受到蒐集策略影響。

#### 資料抓取

1. 3569 部初始影片
2. 篩選影片(跑步 300 部、素描和學習各 250 部，共 800 部)
3. 剔除非英文或非分享活動的影片(40 部)，剩餘 760 部(跑步 273、素描 245、學習 242)
4. 隨機抽樣 420 部，三領域各 140 部[^2]

絕大多數觀看數偏少，每個帳號只允許至多兩部影片，極小部分作者標為網紅影片，觀看數 > 5000。

#### 資料分析

採用<span data-term="inductive-reasoning">歸納法</span>和<span data-term="deductive-reasoning">演繹法</span>混合主題分析。

歸納檢查影片→活動資訊編碼(發現時間很重要，從該角度分析)。

最終 17 個編碼，圍繞影片中數據呈現的三個維度：

1. 影片中資訊的模態（例如：影片、文字、音訊、圖片）
2. 資訊呈現的形式（例如：語音敘述、展示追蹤應用的影片）
3. 分享數據的策略（例如：活動前呈現目標、活動中提供即時評論）。

## 研究發現

有三個貢獻：

- 發現分享者的分享行為可分為三個時段：準備(活動前)、過程(活動中)、反饋(活動後) [^1]
- 發現常用的策略讓分享者呈現資訊，例如進度標記、數字總結等
- 提供設計經驗、想法，幫助創建支持分享的工具

### 準備

人們會分享之前發生的事件或想法，例如計畫，同時會持續揭露目標和進度。

#### 目標呈現

較大目標則會分多部影片呈現。

**我的推測**：因為短影音不具備足夠的時長供分享者講述故事，此外可能原因還有透過多部影片能讓觀眾留下注意力持續追蹤觀看。

分為兩個尺度目標：

1. **影片尺度目標**：指的是在單支影片內能達成的目標，例如晨跑、一次學習、縮時速寫等
2. **更廣尺度目標**：通常是進行中的重要目標，但不會在影片中完成，而且大多需要多次完成，更抽象也沒有確切**結束**事件，例如：提升數學能力、每天跑步直到半程馬拉松等

如果影片同時有兩個尺度目標，通常先描述更廣尺度目標，然後介紹影片尺度目標。

影片比起介紹更廣尺度目標，更常呈現影片尺度目標，這個趨勢存在於三個活動領域中：

以下比例為各類型目標在該領域影片中的出現比例，分類彼此不互斥，因此總和可能超過 100%。

| 目標尺度             | 跑步   | 學習   | 素描 |
| -------------------- | ------ | ------ | ---- |
| 影片尺度目標         | 81.18% | 94.12% | 70%  |
| 更廣尺度目標         | 63.77% | 23.53% | 30%  |
| 同時呈現兩種尺度目標 | 44.93% | 17.65% | 30%  |

不同領域之間同時呈現兩種尺度目標的頻率差異相對較大：跑步有 44.93% 的影片同時呈現兩種尺度目標，相較之下學習為 17.65%、素描為 30%。

例如：先展示是半程馬拉松訓練，然後寫第 XX 天/X 公里。
當然也有影片只介紹更廣尺度目標，例如：一起為 XX 考試學習，但沒寫具體目標。

大部分影片會有文字說明目標，約八成或更高。
此外人們會說明要如何達成目標，分成兩種：

1. 展示需要的裝備或工具
2. 將目標分成子目標，在兩種尺度都有，例如：配速跑幾公里、學習計畫清單
   除此之外人們還會講述設定該目標的原因或影響達成目標的因素

### 過程

#### 進度標記

影片分享者通常會有進度標記講述目前影片在達成目標的過程到哪個進度，可以是影片片段(例如：跑者用手勢表達幾圈、計時器上的學習時間)、文字註解或口頭，說明數字(<span data-term="quantitative-data">量化</span>)或描述(<span data-term="qualitative-data">質化</span>)：

| 領域 | 以數字呈現進度的比例 |
| ---- | -------------------- |
| 跑步 | 22.86%               |
| 學習 | 12.86%               |
| 素描 | 0.72%                |

#### 即時旁白

影片分享者透過文字或音訊等方式提供有關活動的細節，能夠表達自身感受，包含反思、動機。

影片通常同時使用兩者，一個講進度，一個講內容。

### 反饋

#### 結論數值

紀錄進度用，通常是文字或語音呈現。三個領域共有 69 支影片使用結論數值摘要，其中跑步佔了絕大多數：

| 領域 | 使用結論數值摘要的影片數 | 使用此手法的影片中，各領域各佔多少 |
| ---- | ------------------------ | ---------------------------------- |
| 跑步 | 62 支                    | 89.95%                             |
| 學習 | 6 支                     | 8.70%                              |
| 素描 | 1 支                     | 1.45%                              |

(此處指的是使用此手法的 69 支影片中各領域的佔比，並非指「該領域影片本身有多少比例用了這個手法」)

#### 活動後反思

闡述對未來的收穫、感想。在使用結論數值摘要的影片中，有 41.8% 同時包含活動後反思。

另外，分享者在活動後反思中重新提及當初設定目標的比例，因領域而有明顯差異：

| 領域 | 事後反思中重新提及目標的比例 |
| ---- | ---------------------------- |
| 跑步 | 24/56 支(47.86%)             |
| 學習 | 4/32 支(12.5%)               |
| 素描 | 1/14 支(7.14%)               |

跑步者中，若影片同時呈現「影片尺度目標」與「更廣尺度目標」，重新提及目標的比例又更高(15/31 支，48.39%)，高於只呈現影片尺度目標的影片(9/25 支，36%)。

### 敘事策略如何支持不同分享目的

論文引用 Epstein 等人對個人數據分享目的的分類，檢視活動前、中、後三階段常用的敘事策略(呈現目標、進度標記、即時旁白、數字總結、活動後反思)分別如何幫助或阻礙分享者達成分享目的。原始框架共有五項分享目的，但論文在這個部分將「尋求情緒支持」與「表達自身形象」合併成「獲得情感支持與印象管理」一類討論，因此下表以四類分享目的呈現，以「＋」表示益處、「－」表示疑慮，整理成表格：

| 分享目的               | 活動前                                                       | 活動中                                                                                                                                                                     | 活動後                                                                                                     |
| ---------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 獲得資訊性支持         | ＋呈現目標有助於分享活動目標，提升尋求資訊性支持時的清晰度。 | ＋進度標記與即時旁白鼓勵分享更多活動細節，讓觀眾能給出更具體的建議。<br>－重點或疑問可能被埋沒在較長的敘事之中。                                                           | ＋數字總結與活動後反思鼓勵分享者說明哪些問題或建議會有幫助。<br>－重點或疑問仍可能被埋沒在較長的敘事之中。 |
| 獲得情感支持與印象管理 | ＋呈現目標有助於傳達對活動的疑慮或擔憂，進而換得情感支持。   | ＋進度標記與即時旁白支持在進行活動時更充分表達挑戰與情緒，有助於傳達支持需求。<br>－可能因社群比較等壓力，被迫花心力打磨視覺形象，這在其他分享媒介中未必是同等嚴重的顧慮。 | ＋活動後反思有助於呈現達成目標承諾所需的情感支持需求，也提供慶祝成果的機會。                               |
| 尋求觀眾的動力與課責   | ＋呈現目標有助於在活動開始前先公開目標，強化目標承諾。       | ＋進度標記證明活動確實有被執行；進度標記與即時旁白鼓勵提供更詳細的說明，幫助觀眾理解完成這項活動所需的努力。                                                               | ＋數字總結呈現目標承諾的成果，有助於維持課責。                                                             |
| 激勵、告知或影響他人   | ＋呈現目標有助於描述步驟或策略，讓觀眾可以從中學習。         | ＋進度標記描述活動如何完成，以及進行活動時伴隨的正向感受。                                                                                                                 | ＋活動後反思有助於凸顯完成活動後的正向感受。                                                               |

簡單來說：短影音的敘事節奏(先講目標、過程中即時更新、最後總結反思)大致上都對四種分享目的有幫助，主要的代價集中在活動中這一段，也就是內容被壓縮、拆成片段之後，重點容易被稀釋，或是為了呈現而多花心力經營視覺形象。

## 研究限制

- 作者提及影片集中在美國，將研究成果遷移至其他地區須注意
- 以影片為單位而非帳號，觀察多人分享方式，而非某人分享方式
- 一部影片可能只呈現一個活動過程中的某一個階段
  - 如果抽到影片只是其中一階段會有失真
  - 可能是透過多部影片串聯達成目標，缺少觀測長期發展
- 平台內容是否可以遷移成果？
  - 作者認為大多成果可行，但依然可能有不同平台特性影響，例如：ig、fb 注重動態瀏覽者，強調追蹤和演算法推送，短影音可能並非為了策畫的觀眾設計
- 其他領域可能有不同指標
  - 例如：聽覺、觸覺，或者減輕、加重數值(理財、電競)指標之類的
- 影片是透過演算法推薦的動態呈現，分享者可能會受歡迎內容影響而調整自己的分享方式
  - 作者比較過高人氣與低人氣影片的敘事手法，並未發現顯著差異，主要差異在製作精緻度與活動品質本身(例如素描的畫工、跑步沿途的風景)。然而，推薦演算法仍可能影響分享者長期接觸的內容與模仿行為，因此仍可能是值得考慮的潛在因素。

這邊作者提及許多面向，包含我在〈[互動讚數越多，一篇文章就越可信嗎？](/articles/social-engagement-misinformation)〉裡談過的地區限制。

## 結論 & 未來方向

短影音有三個階段分享(準備、過程、反饋)，探討分享者如何在每個階段融入分享活動資訊，包含三個領域。

建議短影音製作工具可以：

- 多鼓勵敘事結構功能(缺點是可能過於公式化，須確保維持個人風格分享)
- 追蹤功能能支援數據整合到影片中
- 引導分享者抓住關鍵點(挑戰、問題)呈現
- 建議分享者列出目標(上述談過的兩者都行)，描述使用設備和工具
- 根據目標和問題突出顯示或標記供搜索

將影片剪輯和活動追蹤工具更緊密整合。

- 數據要格式化或者用截圖或錄製追蹤數據畫面，減低觀眾認知負擔

## 閱讀心得

讀完這篇論文後，我也想到另一個可能的延伸方向。如果將場景從 TikTok 這類公開平台轉移到人數較少、成員具有共同目標的社群，例如讀書、投資或自我成長社群，成員的分享行為是否會有所不同？例如，分享的意願、頻率、內容詳細程度，以及成員之間的互動是否可能受到群體規模或共同目標影響。

[^1]: 並非所有時候都有這三個階段，實際上許多影片可能只有一部份階段，例如只有活動後感想。

[^2]: 作者提到會採用 420 部影片(三領域各 140 部)的樣本量，是因為過去 HCI／CSCW 領域對 TikTok 影片做類似質性分析時，樣本規模通常落在 100 到 300 部之間，作者刻意選在這個範圍的高端，因此定為 420 部。
